# Ícones da Extensão

Adicione seus ícones aqui nos seguintes tamanhos:

- **icon16.png** - 16x16 pixels (aparece na barra de extensões)
- **icon48.png** - 48x48 pixels (página de gerenciamento)
- **icon128.png** - 128x128 pixels (Chrome Web Store)

## Como criar ícones rapidamente:

1. Use [Favicon.io](https://favicon.io/favicon-generator/) para gerar ícones
2. Use [Canva](https://www.canva.com/) com templates de ícone
3. Converta emojis em PNG usando sites online
4. Use ferramentas como GIMP ou Photoshop

## Temporário:
Enquanto não tiver ícones personalizados, você pode:
- Remover as referências aos ícones no manifest.json
- Ou adicionar ícones placeholder aqui
