📋 Instruções:

  1. Personalize o ícone usando os controles acima
  2. Clique em "Baixar Todos os Ícones" para salvar os 3 tamanhos
  3. Salve os arquivos baixados na pasta icons/ do seu projeto
  4. Os arquivos devem ser nomeados: icon16.png, icon48.png, icon128.png
  5. Recarregue a extensão em chrome://extensions/
